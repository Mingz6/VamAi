# VAM Notes Hub

Single source of truth for note-like content under VAM.

## Folders

- `apple-notes/` - markdown exports from Apple Notes
- `apple-notes-html/` - raw HTML snapshots from Apple Notes, including embedded images when present
- `projects/` - handwritten or project-specific markdown logs that used to live inside project folders
