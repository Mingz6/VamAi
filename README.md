# VAM AI

Vancouver AI Meetup — weekly learning group exploring AI/ML tools, frameworks, and projects.

## Structure

| Folder | What goes here |
|--------|---------------|
| `programs/` | Structured courses and hackathons (e.g., VAS, OpenClaw) |
| `meetings/` | Weekly meeting code, experiments, ad-hoc demos |
| `samples/` | Standalone code samples worth keeping |
| `notes/` | Apple Notes exports, meeting notes, project logs |
| `infra/` | Docker configs, deployment files |
| `docs/` | GitHub Pages |

## Active Programs

- [`programs/vas-2025/`](programs/vas-2025/) — Vancouver AI School 2025 (5-week course)
- [`programs/openclaw-q2-2026/`](programs/openclaw-q2-2026/) — OpenClaw Hackathon Q2 2026

## Adding New Content

- **New program/course**: `programs/{name}-{year}/`
- **New hackathon**: `programs/{name}-q{quarter}-{year}/`
- **Weekly meeting code**: `meetings/{year}/{topic-or-date}/`
- **Meeting notes**: `notes/apple-notes/` (auto-exported) or `notes/projects/` (manual logs)
